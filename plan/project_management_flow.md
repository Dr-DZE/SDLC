Вариант использования: Управление проектами

*   **Краткое описание:** Позволяет Менеджеру проектов создавать, просматривать, редактировать и удалять проекты, а также привязывать к ним задачи для организации работы.

*   **Акторы:** Менеджер проектов.

*   **Предусловия:**
    *   Менеджер проектов успешно аутентифицирован в системе.
    *   Система доступна и функционирует.
    *   Менеджер проектов имеет соответствующие права доступа для управления проектами.

*   **Основной поток событий:**
    1.  Вариант использования начинается, когда Менеджер проектов переходит на страницу управления проектами.
    2.  Система отображает список существующих проектов (если они есть) с их основными атрибутами (название, статус, даты) и элементы управления для взаимодействия с проектами (например, кнопки "Добавить проект", "Редактировать", "Удалить").

    3.  **Создание проекта:**
        *   Менеджер проектов нажимает кнопку "Добавить проект".
        *   Система отображает форму для ввода данных нового проекта, включающую поля: "Название", "Описание", "Дата начала", "Дата окончания", "Статус".
        *   Менеджер проектов заполняет обязательные поля и, при необходимости, необязательные.
        *   Менеджер проектов нажимает кнопку "Сохранить" (или "Создать").
        *   Система отправляет введенные данные нового проекта на Сервер.
        *   Сервер валидирует полученные данные.
        *   Если данные корректны, Сервер сохраняет новый проект в базе данных. Если данные некорректны, выполняется альтернативный поток А1.
        *   Сервер отправляет подтверждение успешного создания проекта.
        *   Система обновляет список проектов на странице и отображает новый проект.

    4.  **Просмотр проекта:**
        *   Менеджер проектов выбирает проект из списка (например, кликая по его названию или кнопке "Подробнее").
        *   Система отображает детальную информацию о выбранном проекте, включая список привязанных к нему задач.

    5.  **Редактирование проекта:**
        *   Менеджер проектов выбирает проект из списка и нажимает кнопку "Редактировать".
        *   Система отображает форму редактирования, предзаполненную текущими данными выбранного проекта.
        *   Менеджер проектов изменяет необходимые поля проекта.
        *   Менеджер проектов нажимает кнопку "Сохранить".
        *   Система отправляет измененные данные проекта на Сервер.
        *   Сервер валидирует полученные данные.
        *   Если данные корректны, Сервер обновляет соответствующую запись проекта в базе данных. Если данные некорректны, выполняется альтернативный поток А1.
        *   Сервер отправляет подтверждение успешного обновления проекта.
        *   Система обновляет список проектов на странице и отображает измененный проект.

    6.  **Привязка задачи к проекту:**
        *   Менеджер проектов просматривает детали проекта или редактирует задачу.
        *   Система предоставляет интерфейс для выбора существующей задачи и привязки ее к текущему проекту (например, выпадающий список проектов в форме редактирования задачи или кнопка "Привязать задачу" в деталях проекта).
        *   Менеджер проектов выбирает задачу и проект для привязки.
        *   Система отправляет запрос на Сервер для установления связи между задачей и проектом.
        *   Сервер обновляет данные задачи, устанавливая связь с выбранным проектом.
        *   Сервер отправляет подтверждение успешной привязки.
        *   Система обновляет отображение проекта/задачи, показывая новую связь.

    7.  **Удаление проекта:**
        *   Менеджер проектов выбирает проект из списка и нажимает кнопку "Удалить".
        *   Система может запросить подтверждение удаления (например, диалоговое окно "Вы уверены, что хотите удалить проект?").
        *   Менеджер проектов подтверждает удаление.
        *   Система отправляет запрос на удаление проекта на Сервер.
        *   Сервер удаляет проект из базы данных. (Примечание: бизнес-логика может предусматривать отвязку или каскадное удаление связанных задач).
        *   Сервер отправляет подтверждение успешного удаления проекта.
        *   Система обновляет список проектов на странице, удаленный проект больше не отображается.

    8.  Вариант использования завершается.

*   **Альтернативные потоки событий:**
    *   **А1: Некорректный ввод данных при создании/редактировании проекта.**
        1.  На шаге 3 (создание) или 5 (редактирование) основного потока Сервер определяет, что введенные данные проекта некорректны (например, обязательное поле "Название" пусто, или "Дата окончания" раньше "Даты начала").
        2.  Сервер отправляет сообщение об ошибке в систему, указывая на некорректные поля.
        3.  Система отображает сообщение об ошибке рядом с соответствующими полями формы, подсвечивая их.
        4.  Менеджер проектов может исправить данные и повторить попытку сохранения, вернувшись к шагу, где он заполняет форму.
        5.  Вариант использования продолжается с шага, где Менеджер проектов исправляет данные.

*   **Постусловия:**
    *   **Создание проекта:** Новый проект успешно добавлен в систему, сохранен в базе данных и отображается в списке проектов.
    *   **Просмотр проекта:** Менеджер проектов ознакомился с детальной информацией о проекте.
    *   **Редактирование проекта:** Существующий проект успешно обновлен в системе, изменения сохранены в базе данных и отображаются в списке проектов.
    *   **Привязка задачи:** Задача успешно привязана к проекту, связь сохранена в базе данных.
    *   **Удаление проекта:** Проект успешно удален из системы и базы данных, больше не отображается в списке проектов.
