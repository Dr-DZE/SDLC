Вариант использования: Управление задачами

*   **Краткое описание:** Позволяет авторизованному пользователю создавать, просматривать, редактировать и удалять задачи в системе "To-Do List".

*   **Акторы:** Пользователь, Менеджер проектов.

*   **Предусловия:**
    *   Пользователь успешно аутентифицирован в системе.
    *   Система доступна и функционирует.
    *   Пользователь находится на главной странице или странице, предназначенной для управления задачами.

*   **Основной поток событий:**
    1.  Вариант использования начинается, когда Пользователь просматривает список задач на главной странице или странице задач.
    2.  Система отображает список существующих задач (если они есть) с их основными атрибутами (название, статус, срок выполнения) и элементы управления для взаимодействия с задачами (например, кнопки "Добавить задачу", "Редактировать", "Удалить").

    3.  **Создание задачи:**
        *   Пользователь нажимает кнопку "Добавить задачу".
        *   Система отображает форму для ввода данных новой задачи, включающую поля: "Название", "Описание", "Срок выполнения", "Статус" (по умолчанию "Не выполнено"), "Приоритет".
        *   Пользователь заполняет обязательные поля и, при необходимости, необязательные.
        *   Пользователь нажимает кнопку "Сохранить" (или "Создать").
        *   Система отправляет введенные данные новой задачи на Сервер.
        *   Сервер валидирует полученные данные.
        *   Если данные корректны, Сервер сохраняет новую задачу в базе данных. Если данные некорректны, выполняется альтернативный поток А1.
        *   Сервер отправляет подтверждение успешного создания задачи.
        *   Система обновляет список задач на странице и отображает новую задачу.

    4.  **Просмотр задачи:**
        *   Пользователь выбирает задачу из списка (например, кликая по ее названию или кнопке "Подробнее").
        *   Система отображает детальную информацию о выбранной задаче в отдельном окне или на новой странице.

    5.  **Редактирование задачи:**
        *   Пользователь выбирает задачу из списка и нажимает кнопку "Редактировать".
        *   Система отображает форму редактирования, предзаполненную текущими данными выбранной задачи.
        *   Пользователь изменяет необходимые поля задачи.
        *   Пользователь нажимает кнопку "Сохранить".
        *   Система отправляет измененные данные задачи на Сервер.
        *   Сервер валидирует полученные данные.
        *   Если данные корректны, Сервер обновляет соответствующую запись задачи в базе данных. Если данные некорректны, выполняется альтернативный поток А1.
        *   Сервер отправляет подтверждение успешного обновления задачи.
        *   Система обновляет список задач на странице и отображает измененную задачу.

    6.  **Удаление задачи:**
        *   Пользователь выбирает задачу из списка и нажимает кнопку "Удалить".
        *   Система может запросить подтверждение удаления (например, диалоговое окно "Вы уверены, что хотите удалить задачу?").
        *   Пользователь подтверждает удаление.
        *   Система отправляет запрос на удаление задачи на Сервер.
        *   Сервер удаляет задачу из базы данных.
        *   Сервер отправляет подтверждение успешного удаления задачи.
        *   Система обновляет список задач на странице, удаленная задача больше не отображается.

    7.  Вариант использования завершается.

*   **Альтернативные потоки событий:**
    *   **А1: Некорректный ввод данных при создании/редактировании задачи.**
        1.  На шаге 3 (создание) или 5 (редактирование) основного потока Сервер определяет, что введенные данные задачи некорректны (например, обязательное поле "Название" пусто, или "Срок выполнения" указан в неверном формате).Н
        2.  Сервер отправляет сообщение об ошибке в систему, указывая на некорректные поля.
        3.  Система отображает сообщение об ошибке рядом с соответствующими полями формы, подсвечивая их.
        4.  Пользователь может исправить данные и повторить попытку сохранения, вернувшись к шагу, где он заполняет форму.
        5.  Вариант использования продолжается с шага, где Пользователь исправляет данные.

*   **Постусловия:**
    *   **Создание задачи:** Новая задача успешно добавлена в систему, сохранена в базе данных и отображается в списке задач.
    *   **Просмотр задачи:** Пользователь ознакомился с детальной информацией о задаче.
    *   **Редактирование задачи:** Существующая задача успешно обновлена в системе, изменения сохранены в базе данных и отображаются в списке задач.
    *   **Удаление задачи:** Задача успешно удалена из системы и базы данных, больше не отображается в списке задач.
