Вариант использования: Отслеживание статуса

*   **Краткое описание:** Позволяет авторизованному Пользователю просматривать и изменять статус выполнения задач, а Менеджеру проектов также просматривать и изменять статус проектов.

*   **Акторы:** Пользователь, Менеджер проектов.

*   **Предусловия:**
    *   Пользователь успешно аутентифицирован в системе.
    *   Система доступна и функционирует.
    *   В системе существуют задачи и/или проекты.

*   **Основной поток событий:**
    1.  Вариант использования начинается, когда Пользователь (или Менеджер проектов) просматривает список задач или проектов на соответствующей странице.
    2.  Система отображает текущий статус для каждой задачи (например, "Не выполнено", "В процессе", "Выполнено") и для каждого проекта (например, "Активен", "Завершен", "Приостановлен").

    3.  **Изменение статуса задачи:**
        *   Пользователь выбирает задачу из списка (например, кликая по ней или используя элемент управления рядом с задачей).
        *   Система предоставляет элемент управления для изменения статуса задачи (например, выпадающий список со статусами, чекбокс "Выполнено", кнопка "Изменить статус").
        *   Пользователь выбирает новый статус для задачи.
        *   Система отправляет запрос на Сервер для обновления статуса задачи.
        *   Сервер валидирует изменение статуса (например, проверяет корректность перехода между статусами).
        *   Сервер обновляет статус задачи в базе данных.
        *   Сервер отправляет подтверждение успешного обновления статуса.
        *   Система обновляет отображение статуса задачи в списке.

    4.  **Изменение статуса проекта (только для Менеджера проектов):**
        *   Менеджер проектов выбирает проект из списка.
        *   Система предоставляет элемент управления для изменения статуса проекта.
        *   Менеджер проектов выбирает новый статус для проекта.
        *   Система отправляет запрос на Сервер для обновления статуса проекта.
        *   Сервер валидирует изменение статуса.
        *   Сервер обновляет статус проекта в базе данных.
        *   Сервер отправляет подтверждение успешного обновления статуса.
        *   Система обновляет отображение статуса проекта в списке.

    5.  Вариант использования завершается.

*   **Альтернативные потоки событий:**
    *   **А1: Невозможность изменения статуса.**
        1.  На шаге 3 (для задачи) или 4 (для проекта) основного потока Сервер отклоняет изменение статуса (например, из-за бизнес-правил, таких как невозможность изменить статус завершенного проекта на активный, если есть незавершенные задачи, или отсутствие прав доступа).
        2.  Сервер отправляет сообщение об ошибке в систему, объясняющее причину отказа.
        3.  Система отображает сообщение об ошибке Пользователю (или Менеджеру проектов).
        4.  Вариант использования завершается, статус остается неизменным.

*   **Постусловия:**
    *   Статус задачи или проекта успешно обновлен в системе, сохранен в базе данных и отображается Пользователю (или Менеджеру проектов).
