Вариант использования: Фильтрация и сортировка

*   **Краткое описание:** Позволяет авторизованному Пользователю фильтровать и сортировать списки задач и проектов по различным критериям для удобного просмотра и анализа информации.

*   **Акторы:** Пользователь, Менеджер проектов.

*   **Предусловия:**
    *   Пользователь успешно аутентифицирован в системе.
    *   Система доступна и функционирует.
    *   В системе существуют задачи и/или проекты, которые могут быть отфильтрованы/отсортированы.
    *   Пользователь находится на странице, отображающей списки задач или проектов.

*   **Основной поток событий:**
    1.  Вариант использования начинается, когда Пользователь просматривает список задач или проектов.
    2.  Система отображает список задач/проектов и доступные элементы управления для фильтрации и сортировки (например, выпадающие списки для выбора критериев, поля ввода для значений фильтра, кнопки для применения/сброса).

    3.  **Фильтрация списка:**
        *   Пользователь выбирает один или несколько критериев фильтрации (например, по статусу задачи, приоритету, сроку выполнения, связанному проекту).
        *   Пользователь указывает значения для выбранных критериев фильтрации (например, "Выполнено" для статуса, "Высокий" для приоритета, конкретный проект).
        *   Пользователь нажимает кнопку "Применить фильтр" (или фильтрация происходит автоматически).
        *   Система отправляет запрос на Сервер с выбранными параметрами фильтрации.
        *   Сервер обрабатывает запрос, извлекает из базы данных только те задачи/проекты, которые соответствуют заданным критериям, и возвращает отфильтрованный список.
        *   Система обновляет отображаемый список, показывая только те элементы, которые соответствуют критериям фильтрации.

    4.  **Сортировка списка:**
        *   Пользователь выбирает критерий сортировки (например, по названию, сроку выполнения, дате создания, приоритету).
        *   Пользователь выбирает порядок сортировки (по возрастанию/убыванию).
        *   Пользователь нажимает кнопку "Применить сортировку" (или сортировка происходит автоматически).
        *   Система отправляет запрос на Сервер с выбранными параметрами сортировки.
        *   Сервер обрабатывает запрос, сортирует текущий список задач/проектов в соответствии с указанными параметрами и возвращает отсортированный список.
        *   Система обновляет отображаемый список, показывая элементы в указанном порядке.

    5.  **Комбинированная фильтрация и сортировка:**
        *   Пользователь применяет несколько фильтров и/или сортировок одновременно.
        *   Система отправляет запрос на Сервер с комбинированными параметрами.
        *   Сервер обрабатывает запрос, применяя сначала фильтры, затем сортировку, и возвращает соответствующий список.
        *   Система обновляет отображаемый список.

    6.  Вариант использования завершается.

*   **Альтернативные потоки событий:**
    *   **А1: Некорректные параметры фильтрации/сортировки.**
        1.  На шаге 3 или 4 основного потока Пользователь вводит некорректные или несовместимые параметры (например, текстовое значение для числового фильтра, или выбирает несуществующий критерий).
        2.  Система может предотвратить отправку некорректного запроса, отобразив валидационное сообщение на стороне клиента.
        3.  Если некорректный запрос все же достигает Сервера, Сервер возвращает ошибку.
        4.  Система отображает сообщение об ошибке или предупреждение Пользователю, указывая на некорректные параметры.
        5.  Вариант использования продолжается с шага, где Пользователь корректирует параметры.

*   **Постусловия:**
    *   Список задач или проектов отображается Пользователю в соответствии с примененными фильтрами и сортировкой.
