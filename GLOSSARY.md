| Термин | Определение |
| :--- | :--- |
| **Задача (TodoItem)** | Основная сущность системы; отдельный элемент списка дел, имеющий название, описание, сложность и, опционально, срок выполнения. |
| **Проект (Project)** | Контейнер верхнего уровня для группировки связанных задач. Каждый проект имеет название и цветовую тему. |
| **Трек (TaskTrack)** | Список задач внутри проекта, представляющий собой этап или подкатегорию. Задачи в треке могут быть зависимы друг от друга. |
| **To-Do List (Система)** | Веб-приложение, предназначенное для управления личными задачами и организации работы в рамках структурированных проектов. |
| **Простой режим** | Основной интерфейс приложения для управления персональным списком задач, не привязанных к проектам. |
| **Super Mode (Продвинутый режим)** | Раздел приложения для работы с проектами, который включает в себя два под-режима: "User" и "Dev". |
| **User Mode (Режим пользователя)** | Ограниченный режим в "Super Mode", позволяющий пользователям просматривать проекты и отмечать выполнение задач. |
| **Dev Mode (Режим разработчика)** | Административный режим в "Super Mode", предоставляющий полный доступ к созданию, редактированию и удалению проектов, треков и задач. |
| **Пользователь (User)** | Участник системы, который может управлять задачами. В зависимости от контекста может быть обычным пользователем или менеджером. |
| **Аутентификация (Authentication)** | Процесс входа пользователя в систему для получения доступа к её функциям (в текущей версии упрощена). |
| **Spring Boot** | Основной фреймворк на языке Java, используемый для создания серверной части (backend) приложения. |
| **Thymeleaf** | Серверный шаблонизатор, который используется для генерации HTML-страниц и динамического отображения данных. |
| **Spring Data JPA** | Технология, упрощающая взаимодействие с базой данных путём автоматического создания запросов на основе Java-объектов (сущностей). |
| **H2 Database** | Встраиваемая реляционная база данных, используемая в проекте для хранения всей информации (задач, проектов, треков). |
| **Maven** | Инструмент для автоматизации сборки проекта и управления его зависимостями (библиотеками). |
| **Frontend (Клиентская часть)** | Пользовательский интерфейс, построенный с помощью HTML, CSS и JavaScript, который отображается в браузере. |
| **Backend (Серверная часть)** | Логика приложения, реализованная на Spring Boot, которая обрабатывает HTTP-запросы, взаимодействует с базой данных и управляет бизнес-логикой. |
| **Эндпоинт (Endpoint)** | Конкретный URL-адрес на сервере, к которому обращается клиент для выполнения действия (например, `/add` для добавления задачи). |
| **Контроллер (Controller)** | Компонент Spring, отвечающий за приём и обработку HTTP-запросов от пользователя и возврат результата. |
| **Модель (Model/Entity)** | Java-класс, описывающий структуру данных, хранимых в базе данных (например, `TodoItem`, `Project`). |
| **Репозиторий (Repository)** | Интерфейс в Spring Data JPA, предоставляющий стандартные методы для работы с базой данных (создание, чтение, обновление, удаление). |
| **Безопасность (Security)** | Набор мер, реализованных с помощью Spring Security, для защиты приложения и разграничения доступа (в текущей версии отключено). |
| **SRS (Спецификация требований)** | Документ, описывающий функциональные и нефункциональные требования к программному обеспечению "To-Do List". |
